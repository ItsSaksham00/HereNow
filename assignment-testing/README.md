# HereNow

These tests check working features of the HereNow app.

Requirements: Node.js and npm.

Install from the repository root:

```sh
npm install
```

Run from the repository root:

```sh
node assignment-testing/run.cjs
```

Expected result: 18 automated tests — 12 unit tests and 6 component tests.

Tests use fake/test data and do not require production Supabase access.
